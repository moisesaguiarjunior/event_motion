# Event Motion

- Obtain an independent Astra review before merging changes into the repository's default branch. Give the reviewer the candidate commit, a clear scope, and reproducible checks. Address material findings and obtain a review of the corrected head before merging.
- Record the reviewed commit, Astra's verdict, and the verification in the pull request. Keep implementation and independent review separate.
- For changes to the Dots illustration pipeline, update [the illustration map](docs/mapa-de-ilustracoes.md) and [the mini roadmap](docs/roadmap.md#8-dots-illustration-pipeline) with reusable inputs, commands, and evidence.
